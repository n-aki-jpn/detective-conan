# 状態遷移（設計）
WAITING→VALIDATE_DECKS→SETUP_HIDDEN→SHUFFLE→FIRST_PLAYER→DEAL→MULLIGAN_FIRST→MULLIGAN_SECOND→REVEAL→PLAYING→FINISHED。
AUTO_RESTORE_PARTNER→AUTO_ACTIVATE→AUTO_DRAW→AUTO_FILE→MAIN→END_TRIGGERS→END_EXPIRE→NEXT_TURN。

MAINからの行動:
HAND_PLAY、NEXT_HINT_TAKE→NEXT_HINT_PLAY_OR_PASS、ASSIST、RESOLVE_CASE、DECLARE_ABILITY、DEDUCE、ACTION、END_TURN。
DEDUCE: 宣言→相手ミスリード選択→解決→証拠獲得→終了。
ACTION: 宣言→ガード選択→CONTACTまたはCASE_ACTION。
CONTACT: 順序確定→先の選択→後の選択→条件付き先の再選択→AP判定→終了。
CASE_ACTION: 対象証拠処理→ヒラメキ選択／解決→remove→自分証拠獲得→終了。
各指定境界で効果キューを解決。詳細resolution-timing参照。

turnPlayerIdとdecisionPlayerIdを分離。双方から任意に入力できる同時状態は原則作らない。
割込み: REFRESH、即時置換／無効。選択待ちはWAIT_DECISION。
FINISHED以降のゲーム操作は拒否。NEEDS_RULING/ERROR/TRUNCATEDは公式の勝敗でなく実行停止状態。
