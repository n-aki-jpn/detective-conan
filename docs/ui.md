# UI（設計）
ライフ表示・共有事件・独立バトルフェイズなし。
各自: 現場5枠、パートナー、事件（事件編/解決編と該当先後レベル）、デッキ、FILE、証拠、remove、手札。
FILE／証拠の枚数と順序は表示するが、表面は許可時以外隠す。アシスト中パートナーは区別。
ACTIVE/SLEEP/STUN、名乗り、使用回数、ヒント実行済みを表示。
decisionPlayerに応じてガード、複数ミスリード、コンタクト支援、任意効果、効果順序等のパネルを出す。
事件解決は「使用可能」と「今勝てる」を別表示。U01未確定を開発画面に示す。
プレイヤー表示ログはその時点の可視情報だけ。全知ログは送らない。
ダミー名と記号、AP/LP/レベル、色を表示。公式画像・固有テキストなし。
