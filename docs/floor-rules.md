# イベントプロファイル [F]
BO1が原則(§2.1)。時間30分は推奨で変更可(§2.7)。
時間切れが先攻ターンならそのターンと次の後攻、後攻ならそのターンまで。終了宣言と同時なら次ターンへ移行済み(§2.4)。
未決着は指定方式、指定なしはロジック勝負。両者敗北方式はトーナメント不可(§2.5)。
ロジック勝負: デッキを開始前構成に戻し再シャッフル。各自キャラまで公開、LP比較。同値なら繰返す。片方だけ全公開ならその側敗北、双方ならランダム決着。
両者敗北は両者loss/winnerなし。drawとは異なる。
制限の有無はイベント設定。非適用なら禁止制限も通常3枚まで(§6.2)。
Ver.1.37ダミータグ: BAN_A/BAN_B上限0、LIMIT_A/B/C上限1、EVENT_ONLY_CASE_Aは許可イベントのみ。公式カード対応は同梱しない。
事前登録デッキの変更制限などの大会運用と、エンジン基礎ルールを分離。
記録・電子機器規定(§2.10–2.11)は公式／公認イベントの参加者向け。自主シミュレーターの開発許諾でも禁止許可の包括判断でもない。
ジャッジ裁量や物理ミス修正を自動裁定に置換しない。実装不具合は別途記録・停止。
