# 処理順の確定追記 v0.3.1
根拠: M p.20の欠落アイコンをユーザーが「現場リムーブ時」と確認。
この文書はv0.3の同箇所に優先。

| 種類 | 効果解決中の当該カード | 解決中refreshへの包含 |
|---|---|---|
| 通常イベント | まだremoveではない | 含めない |
| ヒラメキ | まだremoveではない | 含めない |
| カットイン | removeに置かれている | そこにあるなら含める |
| 現場リムーブ時能力 | 現場からremoveへ移動後に効果を解決 | そこにあるなら含める |

現場リムーブ時: 現場→removeの移動を確定し、条件に合致する誘発を記録。通常の解決タイミングで効果を解決する。
「removeに置かれた状態で解決」はその位置を固定する命令ではない。その後の効果やrefreshで移動しても、発動済み効果を消さない。
refresh時には実際にremoveにあるカードだけを使う。sourceInstanceIdのカードを無条件にデッキへ追加しない。
この能力を変装時と混同しない。変装の元カードは元の規則通りデッキ下へ。
