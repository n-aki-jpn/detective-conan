# v0.3.1 差分更新パッケージ
これはv0.3全体版ではなく、ユーザーのアイコン図版確認を反映する差分。
旧ZIPは自動変更されない。v0.3を展開したプロジェクトで以下を実行する。

1. このパッケージのapply_update.pyを実行: python apply_update.py <プロジェクトのルート>
2. docs/open-issues.mdは新規内容で置換される。既存ファイルは.bak-v0.3.1にバックアップ。
3. 他の既存仕様には優先する追記を挿入。対応表・JSONスキーマ・追加テストを追加する。
4. 個別handler実装時にicon-condition-schema.jsonとturn-limit-schema.jsonを検証へ組み込む。

条件スキーマは有効条件用。activationConditionsやresolutionConditionsへ無差別に代入しない。
既存card-schemaのusageLimit整数は互換保持するが、新規実装ではturnLimit構造へ移行する設計とする。自動的な既存JSON書換えは行わない。
確認: JSONスキーマ構造とサンプルの適合、更新スクリプトの仮プロジェクト適用を検証。ゲームテストは未実行。
