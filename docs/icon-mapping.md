# アイコン対応仕様 v0.3.1
更新日: 2026-11-03
根拠: 添付ルールマニュアルVer.2.6の説明と、ユーザーによるPDF図版確認。
公式カード固有名・特徴名はダミー化する。アイコン画像は同梱しない。
この文書はv0.3のアイコン未確認記述に優先する。個別カードの裁定完了を意味しない。

## 能力種別・発動タイミング
| 表記 | 内部キー | 意味 |
|---|---|---|
| 登場時 | onEnterField | 現場に登場したとき |
| 現場リムーブ時 | onRemovedFromField | 現場からリムーブされたとき |
| 変装時 | onDisguise | 変装で現場に現れたとき |
| 疾風 | firstEntryThisTurn | 自分の現場にそのターンで最初に登場したとき |
| 宣言 | declared | プレイヤーが使用を選ぶ能力 |
疾風と迅速は別。疾風は先の登場履歴に基づく誘発、迅速は名乗り中の推理／アクションの許可。
疾風は相手ターンでも条件を満たせば発動。同時に最初の複数枚が登場した場合は対象すべてが条件を満たし得る。1枚ずつ順番に処理して先頭1枚だけにしない。

## 有効条件
| 図版例 | 内部kind | パラメーター／判定 |
|---|---|---|
| 自分ターン中 | ownTurn | turnPlayerId == ownerId |
| 相手ターン中 | opponentTurn | turnPlayerId != ownerId |
| パートナー青 | partnerHasColor | color=blue |
| 事件白 | caseHasColor | color=white |
| 事件YAIBA | caseHasTrait | trait=TRAIT_A |
| FILE5 | minFileCount | count=5、以上。アシスト中パートナーも数える |
| 事件編 | casePhase | phase=INTRO |
| 解決編 | casePhase | phase=RESOLUTION |
| 絆カード名 | bondName | nameKey=NAME_A、自分の現場のキャラ。パートナーでは満たさない |
色・数値・名称参照はパラメーター。青・白・5専用の実装にしない。
複数の条件はすべて満たす必要あり。色のAND指定も全色判定。通常手札使用の色制限と能力の有効条件を混同しない。
事件の指定特徴はTRAIT_*、絆の指定名はNAME_*へ対応を保ってダミー化。

## 回数制限
ターン1→limit=1、ターン2→limit=2、scope=eachTurn。
自分のターン限定という意味ではない。自分／相手ターン条件とは独立。
誘発能力は上限内で条件成立なら原則発動し、発動させないことは選択できない。宣言能力は上限内で任意使用。
設計: source instanceとability idとturn idで回数を管理。同名の別実体を一律共有しない。ただし個別カードに特別な制約があれば別途定義する。
移動・変装等を伴う回数カウンター継承の複雑な相互作用は、対応カードごとに検証する。

## 条件と使用可否
この表の条件は能力／効果の有効条件。全てをcanUseActionの条件へ機械的に転用しない。
効果条件不成立のイベント・カットイン・ヒラメキ等の扱いは既存rulesの種別別規則を維持。
発動済み効果は、発生源離脱や条件不成立だけでは消さない。
