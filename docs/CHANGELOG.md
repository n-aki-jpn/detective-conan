# v0.3 変更点
- カットインは効果解決前にリムーブへ移動する。以前の逆順を訂正。
- 通常イベント／ヒラメキは効果解決中にリムーブへ置かない。
- PDF20ページで欠落したアイコンを変装と断定した記述を撤回。
- 事件解決の証拠枚数をコストから除外。解決時の条件と使用条件を分離。
- 証拠不足での宣言可否は公式訂正文からの解釈として管理。直接Q&A未確認を明記。
- カード訂正適用日、正規ID、定義バージョン、テキストなし版の参照を追加。
- 効果の有効性と使用可否を分離。常に有効条件を合法手の条件へ転用しない。
- コストと効果の移動原因、発生源から独立した未解決効果を追加。
- 段階別の中止・続行条件、decisionId、秘密情報分離を追加。
- 特殊勝利を共通終了処理へ統合。
- 過去のZIPは自動変更されない。この新しい一式に置き換える。
