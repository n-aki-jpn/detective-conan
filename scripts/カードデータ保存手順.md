# 公式カード検索データ保存
この添付物は保存用スクリプトであり、全カードデータ本体ではありません。この環境ではネットワーク実行未検証です。
Python 3で python save_conan_cards.py を実行すると公式JSONの応答を保存します。外部ライブラリ不要。
保存: 原本JSON、日本語可読JSON、JSONL、CSV、取得情報とSHA256のmanifest。
公式画像は取得しません。パラレル・別版を削除せず保存し、全フィールドを維持します。
JSON構文・カード配列・ページング・サーバー件数を確認。件数が提供されない場合、検索画面との一致は別途確認が必要と記録します。
ダミー化は原本保存後の別処理です。原本を公開アプリへそのまま同梱するものではありません。
