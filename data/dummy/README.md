# U06 ダミーデッキ設計 v1
非公開・基本エンジン検証向け。全数値・名称は合成データであり公式カードの再現ではない。
40枚（14種類）、パートナー1枚、事件1枚。同じdeckをA/Bがそれぞれ所有し、実体IDと乱数を別にする。
全青・キャラのみ。イベント等を除くため、カード効果のない基本経路から検証できる。
partner lp=1、case first=7/second=6はテスト設定。公式全事件の固定値ではない。
partner abilities=[]でもエンジン共通行動のassist/caseResolutionは必須実装。事件は開始時INTRO。
数値は強さや公平性を保証しない。先後とシャッフルを入替えて評価する。

## 検証対象
通常使用→FILEを消費しない。ヒント→取得後に使用レベル再判定。通常使用/ヒント順序制約。
登場ターンの推理/行動不可、ガード可。キャラ推理LP0と1、partner推理、スイッチ、AP同値、事件行動、アシスト、refresh、事件解決。
高レベルの手札詰まりと低LPの選択を意図的に含む。ランダムCPUの勝率をゲーム本来のカードバランスと解釈しない。
